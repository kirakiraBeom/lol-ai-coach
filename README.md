# LOL AI Coach

Riot API와 MCP를 활용한 개인 맞춤형
리그 오브 레전드 AI 코칭 시스템

## 프로젝트 목적

- Riot API를 활용한 게임 전적 조회
- 바텀 듀오 경기 분석
- 챔피언 조합별 승률 분석
- 경기 타임라인 분석
- ChatGPT MCP 연동
- Python 및 백엔드 개발 학습

## 기술 스택

- Python
- MCP SDK
- HTTPX
- Python-dotenv
- SQLite (도입 예정)
- Git & GitHub

- OS: Windows
- IDE: Visual Studio Code

## Features

- Riot 계정 정보 조회
- 솔로 랭크 정보 조회
- 최근 경기 전적 조회
- 다시하기 경기 별도 처리
- JSON 기반 사용자 설정
- 공통 경기 자동 탐색
- 바텀 듀오 경기 분류
- 듀오 승률 및 평균 KDA 분석
- 챔피언 조합별 승률 분석
